# Non-Delay-Dual-LED-Flasher
A demonstration of multi-tasking in Arduino using the `millis()` function to toggle two LEDs at different frequencies without using `delay()`
## How it works
<b> LED 1 (Pin 12) : </b> Toggle between 0.5 sec (500ms).
<b> LED 2 (Pin 13) : </b> Toggle between 0.2 sec (200ms).
## Components
- Arduino Uno
- 2 LEDs
- 2 Resistors (200ohm)
- Jumper wires
